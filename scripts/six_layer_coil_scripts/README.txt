Six-layer CW/CCW spiral coil KiCad Python scripts
Run via KiCad PCB Editor Python console, 6-layer board and /COIL+ net required.
50-turn option: 0.16/0.10 mm trace/space.
74-turn option: 0.09/0.09 mm trace/space (experimental).
The pcbnew API is not available in the test environment: tests use a simulated KiCad pcbnew interface. Run KiCad DRC and fabrication review.
